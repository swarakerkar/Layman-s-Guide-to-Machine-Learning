# Data Preprocessing on Raw Dataset

This experiment focuses on preprocessing a raw employee dataset using Python and its data science libraries. It covers the basics of handling missing values, encoding categorical data, and scaling numerical features to make the dataset suitable for further Machine Learning tasks.

The goal is to understand how raw, messy data can be transformed into clean, structured, and meaningful data — because good Machine Learning starts with good data!

### Dataset

The dataset used in this experiment is `Employee.csv`, containing employee-related information such as:

- Company
- Age
- Salary
- Place
- Country
- Gender

### Prerequisites

- Basic understanding of Python
- Familiarity with basic mathematics
- Python libraries: NumPy, pandas, Matplotlib, Seaborn, and scikit-learn
- A laptop and the will to learn

### Libraries Used

- **NumPy:** Numerical operations
- **pandas:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **scikit-learn:** Encoding and feature scaling

### What You'll Learn

- Loading and exploring a raw dataset
- Identifying and handling missing values
- Understanding categorical and numerical features
- Encoding categorical variables
- Applying standardization and normalization
- Preparing employee data for Machine Learning
