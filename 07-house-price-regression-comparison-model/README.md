# House Price Predictor: Regression Showdown 

This project explores and compares different Machine Learning regression algorithms to predict house prices.

Using a housing dataset, we train multiple models, including Linear Regression, Decision Tree Regression, Random Forest Regression, and Support Vector Regression (SVR). We evaluate their performance using regression metrics and cross-validation, then tune the best-performing model to improve its predictions.

Four algorithms enter, but which one predicts house prices best? Let's find out!

### Dataset
The experiment uses a housing dataset containing 545 records and 12 input features, including:
- Area
- Number of bedrooms and bathrooms
- Number of stories
- Main road accessibility
- Guestroom and basement availability
- Hot water heating and air conditioning
- Parking spaces
- Preferred area
- Furnishing status

The target variable is **price**.

### Prerequisites
- Basic understanding of Python and mathematics
- Familiarity with basic statistics and regression
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, and scikit-learn

### Libraries Used
- **NumPy & pandas:** Numerical operations and data handling
- **Matplotlib:** Data visualization
- **scikit-learn:** Model training, preprocessing, cross-validation, and hyperparameter tuning
- **LinearRegression:** Predicting prices using linear relationships
- **DecisionTreeRegressor:** Learning decision-based patterns
- **RandomForestRegressor:** Combining multiple decision trees
- **SVR:** Predicting values using Support Vector Regression
- **GridSearchCV:** Searching for suitable model parameters

### What You'll Learn
- Understanding and comparing different regression algorithms
- Preparing numerical and categorical features for modeling
- Applying feature scaling and one-hot encoding
- Splitting data into training and testing sets
- Evaluating predictions using MAE, MSE, RMSE, and R²
- Comparing models using cross-validation
- Tuning model hyperparameters using GridSearchCV
- Identifying a suitable regression model for house price prediction

Because predicting a house price is more than drawing a straight line, let's discover which model captures the patterns best!
