# PCA Dimension Decoder

This project explores Principal Component Analysis (PCA), a dimensionality reduction technique that helps simplify multivariate datasets while preserving as much of their important information as possible.

Using a dataset containing height, weight, age, and gender, we apply PCA to transform the original features into a lower-dimensional representation and investigate how much variance is retained. We also explore how dimensionality reduction can be used alongside Machine Learning models.

### Dataset

A small, manually created multivariate dataset containing:

- Height
- Weight
- Age
- Gender

### Prerequisites

- Basic understanding of Python and linear algebra
- Familiarity with basic statistics
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, Seaborn, and scikit-learn

### Libraries Used

- **NumPy & pandas:** Numerical operations and data handling
- **Matplotlib & Seaborn:** Data visualization
- **StandardScaler:** Standardizing numerical features
- **PCA:** Reducing the dimensionality of the dataset
- **Logistic Regression:** Exploring classification using transformed features

### What You'll Learn

- Understanding dimensionality reduction
- Standardizing features before applying PCA
- Transforming multivariate data into principal components
- Visualizing data in lower dimensions
- Evaluating explained variance and information retention
- Exploring PCA as a preprocessing step for Machine Learning

The idea is simple: can we represent data using fewer dimensions without losing too much of what makes it useful?
