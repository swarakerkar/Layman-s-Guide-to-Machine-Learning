# Regression Playground

This project explores Linear Regression and Logistic Regression, two fundamental Machine Learning algorithms used to make predictions and uncover patterns in data.

Using a housing dataset to predict house prices and a classification dataset to explore Logistic Regression, we get hands-on experience with how machines learn from data. Because predicting a number and predicting a category are two different problems — and understanding that difference is where the fun begins!

### Datasets

- **USA Housing Dataset:** Contains features such as average area income, house age, number of rooms, population, and house prices.
- **Diabetes Dataset:** Used for implementing and evaluating Logistic Regression, as applicable to the notebook.

### Prerequisites

- Basic understanding of Python and mathematics
- Familiarity with basic statistics
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, Seaborn, and scikit-learn

### Libraries Used

- **NumPy & pandas:** Numerical operations and data manipulation
- **Matplotlib & Seaborn:** Data visualization
- **scikit-learn:** Model training, preprocessing, and evaluation

### What You'll Learn

- Understanding Linear Regression and Logistic Regression
- Splitting data into training and testing sets
- Training models using scikit-learn
- Predicting continuous values and classification outcomes
- Evaluating models using appropriate performance metrics
- Understanding cross-validation, confusion matrices, and ROC-AUC where applicable

Happy Learning!
