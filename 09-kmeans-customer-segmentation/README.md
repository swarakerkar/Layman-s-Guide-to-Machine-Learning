# Customer Clustering Lab: The Mall Edition 

What if a mall could understand its customers without being told what groups to look for?

This project explores **K-Means Clustering**, an unsupervised Machine Learning algorithm that groups customers based on similarities in their age, annual income, and spending behaviour.

We go beyond basic clustering by using the Elbow Method and Silhouette Score to select a suitable number of clusters, visualizing customer groups in two and three dimensions, profiling the resulting segments, and exploring how new customers can be assigned to existing clusters.

No predefined labels. No fixed categories. Just data revealing hidden customer patterns!

### Dataset
The experiment uses the Mall Customers dataset, containing 200 customer records with the following features:
- **Age:** Customer's age
- **Annual Income:** Annual income in thousands of dollars
- **Spending Score:** A score from 1 to 100 representing customer spending behaviour

The dataset also includes customer IDs and gender information.

### Prerequisites
- Basic understanding of Python and mathematics
- Familiarity with basic statistics and Machine Learning
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, Seaborn, and scikit-learn

### Libraries Used
- **NumPy & pandas:** Numerical operations and data handling
- **Matplotlib & Seaborn:** Data visualization
- **StandardScaler:** Feature scaling
- **KMeans:** Customer clustering
- **Silhouette Score:** Evaluating cluster separation and cohesion

### What You'll Learn
- Exploring and preprocessing customer data
- Selecting relevant features for clustering
- Understanding why feature scaling matters
- Finding a suitable number of clusters using the Elbow Method
- Evaluating clusters using the Silhouette Score
- Visualizing customer segments in 2D and 3D
- Profiling clusters based on income, age, and spending behaviour
- Assigning new customers to existing clusters

From budget-conscious shoppers to high-spending customers, let's uncover the patterns hiding in the mall!

Happy Learning!
