Advanced Customer Segmentation Using K-Means Clustering¶

Objective¶

To segment mall customers into meaningful groups using the K-Means clustering algorithm and analyze their income, age, and spending behavior.

Advanced Features¶

  • Data preprocessing and feature scaling
  • Elbow method and silhouette score analysis
  • Optimal cluster selection
  • Two-dimensional and three-dimensional visualization
  • Customer segment profiling
  • Prediction of cluster membership for new customers

cluster_range = range(2, 11)

wcss = []
silhouette_scores = []

for k in cluster_range:
    model = KMeans(
        n_clusters=k,
        init="k-means++",
        n_init=10,
        random_state=42
    )

    labels = model.fit_predict(X_scaled)

    wcss.append(model.inertia_)
    silhouette_scores.append(
        silhouette_score(X_scaled, labels)
    )

results = pd.DataFrame({
    "Number of Clusters": list(cluster_range),
    "WCSS": wcss,
    "Silhouette Score": silhouette_scores
})

display(results.round(4))

income_median = df_clustered["Annual Income (k$)"].median()
spending_median = df_clustered["Spending Score (1-100)"].median()

for cluster_id, row in cluster_summary.iterrows():
    income = row["Average_Income"]
    spending = row["Average_Spending"]

    if income >= income_median and spending >= spending_median:
        segment = "High-income, high-spending customers"
        recommendation = "Offer loyalty rewards and premium products."

    elif income >= income_median and spending < spending_median:
        segment = "High-income, low-spending customers"
        recommendation = "Use personalized offers to encourage purchases."

    elif income < income_median and spending >= spending_median:
        segment = "Lower-income, high-spending customers"
        recommendation = "Promote value deals and suitable loyalty benefits."

    else:
        segment = "Lower-income, low-spending customers"
        recommendation = "Use budget-friendly promotions and targeted campaigns."

    print(f"\nCluster {cluster_id}: {segment}")
    print(f"Customers: {int(row['Customer_Count'])}")
    print(f"Recommendation: {recommendation}")

Conclusion¶

The K-Means clustering algorithm was implemented on the Mall Customers dataset to identify groups of customers with similar age, annual income, and spending behavior. Feature scaling was applied to improve distance-based clustering, while the elbow method and silhouette score were used to evaluate the number of clusters. The resulting segments were visualized and analyzed to derive customer profiles and possible marketing strategies. The trained model can also assign new customers to existing clusters.
