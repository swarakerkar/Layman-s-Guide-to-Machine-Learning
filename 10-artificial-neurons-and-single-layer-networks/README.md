# Neural Network Playground: Perceptron vs ADALINE 

How does a machine learn to separate two classes using simple artificial neurons?

This project explores the foundations of neural networks by implementing the **Perceptron** and **ADALINE (Adaptive Linear Neuron)** algorithms from scratch using NumPy. Using two Iris flower species, Setosa and Versicolor, we investigate how artificial neurons learn from data, update their weights, and create decision boundaries.

Going a step further, we compare batch gradient descent with stochastic gradient descent, visualize learning errors and cost convergence, and evaluate the models on unseen data.

### Dataset
The experiment uses the Iris dataset, focusing on 100 samples belonging to two species:
- **Setosa**
- **Versicolor**

Two features are selected for classification:
- Sepal length
- Petal length

### Prerequisites
- Basic understanding of Python and mathematics
- Familiarity with vectors, weights, and basic Machine Learning concepts
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, and scikit-learn

### Libraries Used
- **NumPy:** Implementing artificial neurons and learning algorithms
- **pandas:** Organizing and inspecting the dataset
- **Matplotlib:** Visualizing data, learning curves, and decision boundaries
- **scikit-learn:** Dataset loading, feature standardization, data splitting, and model evaluation

### What You'll Learn
- Understanding artificial neurons and threshold activation
- Implementing the Perceptron learning algorithm from scratch
- Implementing ADALINE using batch gradient descent and the delta rule
- Exploring ADALINE with stochastic gradient descent
- Standardizing features and splitting data using stratified sampling
- Visualizing training errors and cost convergence
- Plotting and comparing decision boundaries
- Evaluating accuracy, confusion matrices, and classification reports
- Comparing model performance on unseen data

Small neurons, simple rules, and the beginnings of a much bigger idea: neural networks!

Happy Learning!
