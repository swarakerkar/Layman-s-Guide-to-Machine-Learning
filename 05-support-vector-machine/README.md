# Pulsar Classifier

This project explores Support Vector Machines (SVM), a Machine Learning algorithm used to classify data by finding decision boundaries that separate different classes.

Using the Pulsar Star dataset, we investigate how SVM can distinguish pulsar candidates from non-pulsar signals. From feature scaling to kernel comparisons and hyperparameter tuning, this experiment takes us a step closer to understanding how classification algorithms learn from real-world scientific data.

### Dataset

The experiment uses the Pulsar Star dataset, containing 17,898 observations and 8 numerical features describing integrated pulse profiles and DM-SNR curves, along with a target class.

### Prerequisites

- Basic understanding of Python and mathematics
- Familiarity with basic statistics and classification
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, Seaborn, and scikit-learn

### Libraries Used

- **NumPy & pandas:** Numerical operations and data handling
- **Matplotlib & Seaborn:** Data visualization
- **StandardScaler:** Feature scaling
- **SVC:** Implementing SVM classifiers
- **GridSearchCV:** Hyperparameter tuning
- **PCA:** Dimensionality reduction and visualization
- **scikit-learn metrics:** Evaluating classification performance

### What You'll Learn

- Understanding the working principle of SVM
- Implementing linear and non-linear SVM classifiers
- Comparing different kernel functions
- Preprocessing data and scaling features
- Evaluating classification using precision, recall, F1-score, and ROC-AUC
- Visualizing confusion matrices and classification performance
- Optimizing hyperparameters using GridSearchCV

Can a machine learn to distinguish a pulsar signal from the noise? Let's find out!
