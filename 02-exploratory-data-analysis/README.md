# Exploratory Data Analysis (EDA)

This experiment focuses on exploring and understanding a dataset using Exploratory Data Analysis (EDA). Using the Titanic passenger dataset, we investigate its structure, features, data types, and basic statistical properties to uncover what the data has to tell us.

Before building a Machine Learning model, it is important to understand the data we're working with — its patterns, inconsistencies, missing values, and hidden insights. That's exactly where EDA comes in!

### Dataset

The experiment uses the Titanic training dataset, containing information about 891 passengers, including:

- Passenger ID
- Survival status
- Passenger class
- Name and gender
- Age
- Number of siblings, spouses, parents, and children aboard
- Ticket information and fare
- Cabin and port of embarkation

### Prerequisites

- Basic understanding of Python
- Familiarity with basic statistics
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, and Seaborn

### Libraries Used

- **NumPy:** Numerical operations
- **pandas:** Data loading, inspection, and manipulation
- **Matplotlib:** Data visualization
- **Seaborn:** Statistical data visualization

### What You'll Learn

- Loading and inspecting a dataset
- Understanding dataset dimensions and column data types
- Examining the first and last few records
- Identifying missing values and data quality issues
- Exploring numerical and categorical features
- Building a foundation for further statistical analysis and visualization
