# Iris Classifier Showdown 

Six algorithms, three flower species, and one question: which classifier performs best?

This project explores and compares six popular Machine Learning classification algorithms using the Iris dataset. We evaluate Logistic Regression, Decision Tree, Random Forest, Support Vector Machine (SVM), K-Nearest Neighbours (KNN), and Gaussian Naive Bayes using Accuracy, Precision, and Recall.

Through data visualization, confusion matrices, and cross-validation, we investigate how different algorithms learn patterns and classify flowers.

### Dataset
The experiment uses the Iris dataset, containing 150 flower samples, four numerical features, and three species:
- **Setosa**
- **Versicolor**
- **Virginica**

The features include sepal length, sepal width, petal length, and petal width.

### Prerequisites
- Basic understanding of Python and mathematics
- Familiarity with basic statistics and classification
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, Seaborn, and scikit-learn

### Libraries Used
- **NumPy & pandas:** Numerical operations and data handling
- **Matplotlib & Seaborn:** Data visualization and correlation analysis
- **scikit-learn:** Model training, preprocessing, and evaluation
- **Logistic Regression, Decision Tree, and Random Forest:** Classification using different learning approaches
- **SVC:** Support Vector Machine classification
- **KNeighborsClassifier:** Classification using nearest neighbours
- **GaussianNB:** Probabilistic classification using Bayes' theorem

Different algorithms, different approaches, but the same goal: making better predictions!
