# Iris Classifier: Tree vs Neighbours 

This project explores two popular Machine Learning algorithms for classification: **Decision Trees** and **K-Nearest Neighbours (KNN)**.

Using the Iris dataset, we train models to identify flower species based on their sepal and petal measurements. We also evaluate their performance using classification metrics and visualize the results to understand how different algorithms learn from the same data.

Can a tree of decisions or a flower's nearest neighbours make the better prediction? Let's find out!

### Dataset
The experiment uses the Iris dataset, containing 150 flower samples with four numerical features and three species:
- **Setosa**
- **Versicolor**
- **Virginica**

Each sample includes sepal length, sepal width, petal length, and petal width.

### Prerequisites
- Basic understanding of Python and mathematics
- Familiarity with basic statistics and classification
- A laptop and the will to learn
- Python libraries: NumPy, pandas, Matplotlib, and scikit-learn

### Libraries Used
- **NumPy & pandas:** Numerical operations and data handling
- **Matplotlib:** Data visualization
- **DecisionTreeClassifier:** Building decision-based classification models
- **KNeighborsClassifier:** Classifying samples using their nearest neighbours
- **StandardScaler:** Feature scaling
- **scikit-learn metrics:** Evaluating model performance

### What You'll Learn
- Understanding Decision Tree and KNN algorithms
- Splitting data into training and testing sets
- Understanding why feature scaling matters for KNN
- Visualizing a trained Decision Tree
- Evaluating models using accuracy, precision, recall, and F1-score
- Analyzing confusion matrices and classification reports
- Comparing the performance of two classification algorithms

Two algorithms, one dataset, three flower species. Let's see which one learns the patterns best!
